# Triple-O Companion App
A lightweight, single-file roller for player character emulation.  
For use with Triple-O, available at [https://capacle.itch.io/triple-o-zine](https://capacle.itch.io/triple-o-zine)

- Click to roll the Triple-O check, with the option to Double Down
- Click to roll on individual random tables or entire sections
- Manage your characters with in-built Trait Sheets
- Save rolls to the scratchpad to keep track of your creations
- Edit the text in the scratchpad freely


## Live version
https://capacle.github.io/triple-o/

## Offline use
Download `index.html` and open it in any browser.
